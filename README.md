# Jarred & Mbali Du Plessis — Wedding RSVP 💍

An elegant, responsive wedding RSVP website built with HTML, CSS, and vanilla JavaScript. Guests can view wedding details, check the countdown, confirm or decline attendance, select additional guests, and receive a personalised confirmation screen.

## ✨ Features

- **Live Wedding Countdown:** Counts down to the wedding date in days, hours, minutes, and seconds.
- **Wedding Details:** Displays the date, venue, dress code, and event schedule.
- **RSVP Form:** Allows guests to accept or decline the invitation using their first name and surname.
- **Additional Guests:** Lets attending guests select up to two additional guests.
- **Personalised Confirmation:** Displays a response message and a guest-pass-style card for attendees.
- **Google Calendar Integration:** Provides a link to add the wedding event to Google Calendar.
- **Confetti Animation:** Adds a celebratory animation when a guest accepts.
- **Responsive Design:** Uses a layout designed for different screen sizes.
- **Elegant UI:** Features warm neutral colours, gold accents, rounded cards, and subtle shadows.

## 🛠️ Built With

Alternatively, open the project in Visual Studio Code and use the Live Server extension.

## ⚠️ Current Limitations

This project is currently a front-end demo rather than a complete RSVP management system.

- RSVP submissions are handled in the browser and are not saved to a database.
- Guest counts and pass numbers are randomly generated, not actual attendance totals or unique reservations.
- The displayed limit of 825 guests is not enforced across multiple visitors.
- Refreshing the page clears the displayed confirmation.
- The Google Calendar link uses fixed event dates and times; its time zone should be checked before launch.
- Google Fonts requires an internet connection to load the intended typefaces.

**For production use:** Connect the RSVP form to a backend or form service, store responses securely, enforce guest limits on the server, and generate unique confirmation references.
