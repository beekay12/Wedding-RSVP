Jarred & Mbali Du Plessis — Wedding RSVP 💍
An elegant, responsive wedding RSVP webpage for Jarred and Mbali Du Plessis. Guests can view the wedding details, check the countdown, confirm or decline attendance, select additional guests, and view a personalised confirmation screen.
✨ Features
- Wedding countdown — live countdown to the wedding date.
- Event details — displays the date, venue, dress code, and wedding schedule.
- RSVP form — guests enter their first name and surname and accept or decline the invitation.
- Additional guests — attending guests can choose up to two additional guests.
- Confirmation screen — displays a personalised response and a guest-pass style card for attendees.
- Google Calendar link — attendees can open a pre-filled Google Calendar event.
- Confetti animation — celebratory animation after an acceptance.
- Responsive styling — layout designed to work across different screen sizes.
- Elegant visual design — warm neutral colours, gold accents, and Google Fonts.

⚠️ Important Limitations
This project is currently a front-end demo, not a complete RSVP management system.
- RSVP responses are processed in the browser only. They are not sent to the couple or stored in a database.
- The displayed guest count and pass number are generated randomly; they are not a real attendance total or unique, reserved ticket number.
- The limit of 825 is displayed in the interface, but the code does not enforce a shared guest capacity.
- Refreshing the page loses the displayed confirmation.
- The Google Calendar link uses fixed event dates and times. Check the time zone and event duration before publishing.
- The page loads Google Fonts from the internet, so the intended fonts may not load offline.
Before using this for real wedding RSVPs: connect the form to a backend or form service, store responses securely, validate guest limits on the server, and generate genuinely unique confirmation references.
